# Revit 2025/2026 acceptance checks

Use disposable projects after deploying `supabase/keynote_annotation_library.sql` and running its SQL acceptance script.

1. Existing projects still open in Text File mode. Verify editing, saving, both placement modes, and Create Text File (including cancellation and assignment failure).
2. Switch a saved project to Generic Annotation Only. First setup copies the assigned file when valid, otherwise the Supabase template. Switching again must preserve cloud edits instead of reseeding. An unsaved project must ask to be saved first.
3. Save divisions, nested notes, blank descriptions, and Unicode. Reopen the manager without saving/synchronizing the RVT: cloud library edits must remain. No DataStorage/Extensible Storage library is created.
4. Open two locals of the same central project. Save in A, Refresh B without Revit Reload Latest: B must receive the new notes. Concurrent edits must conflict and preserve unsaved editor changes. Verify claims and realtime notifications.
5. Disconnect Supabase. Loading/saving/placement must fail clearly without writing a text file or RVT library. Failed saves retain editor changes; reconnect and Refresh to check whether a timed-out save reached the server.
6. Force a family update failure after a cloud save. Confirm database changes remain saved and failed Revit updates roll back. Release ownership and use Update Family Types to retry. Native keynote references must remain unchanged.
7. Place Generic Annotation notes without a keynote file. Verify latest cloud version is checked, User Keynote placement is disabled, missing family/arrowhead errors are actionable, and model issues/analytics use annotation-only counts.
8. Switching modes with dirty edits must support cancel/discard. A new project path identifies a separate cloud library. Revit Save/Sync persists family changes and placed annotations only, never the library.
9. Convert Generic Annotation Only to Text File with divisions, nested notes, Unicode, blank descriptions, and unplaced notes. Both selecting Text File and clicking Export Library to Text File must open Save As and export every saved row, including cloud edits saved while the dialog is open. Verify UTF-16, Revit assignment, and the existing Supabase library's updated path, hash, timestamp, and file source type. Library and entry IDs, claims, and analytics must be retained with no second library. Cancel, reject an existing filename, and force assignment failure: the mode must remain Generic Annotation Only. Interrupt Supabase or save a concurrent cloud edit during export: Revit assignment must roll back and the mode must remain unchanged; the export stays on disk. Refresh must resolve the original project identity even if a successful database response was lost. Retry conversion, then return to Generic Annotation Only and verify the same library ID is reused.
